AI 편집은 내장 imagegen을 사용했습니다. 편집 지시는 공통적으로 **원본 UI·문구·상태를 유지하며 개인정보 영역에 불투명 가림을 적용하고 새 결과를 만들지 않는 것**입니다. 이미지가 재생성되는 특성상 원본과 픽셀·글꼴·해상도가 동일하지 않을 수 있어 모두 `ai-edited`로 표시했습니다. 사실 판단은 원본 비공개 검토·사용자 제공 출력·성공 보고를 기준으로 합니다.

### 편집 지시 요약

- 웹 화면: 홈 경로, 세션 식별자와 우측 대화 목록을 가리고 모델·도구·메뉴 유지.
- 모바일 화면: 홈 경로와 세션 식별자를 가리고 세로 화면 유지.
- 로그인 화면: 계정과 비밀번호 영역 전체를 가리고 로그인 제한 문구 유지.
- 접속 오류: 주소만 가리고 시간 초과 오류 문구 유지.
- Uptime Kuma: 서비스 URL과 계정 표시를 가리고 기존 감시 항목·상태 유지.

각 편집본은 화면 검토와 OCR로 가림 상태를 확인했습니다. 원본 파일을 편집본으로 덮어쓰지 않았습니다. 기존 `01`~`08` 이미지는 이번 작업에서 삭제하거나 바꾸지 않았으며 종전 문서의 원본·AI 편집 구분을 유지합니다.

## 공개하지 않은 대표 자료

- Beszel 등록 토큰·공개 키가 포함된 시스템 추가 화면.
- Tailscale 기기 목록·실제 계정·IP·호스트가 드러나는 상태 출력.
- DHCP 예약의 IP·MAC과 공유기 포트포워딩·UPnP 목록.
- 실제 서비스 포트 묶음과 기기 식별자가 담긴 접근 정책 전체.
- 로컬 계정 경로가 보이는 Orca 스킬 설치 입력 화면. 설치 성공 근거는 별도 사용자 제공 CLI 완료 출력으로 정리.
- 동일 장면의 중복 캡처와 결과가 없는 초기 설정 화면.

기능을 설명하는 데 충분한 비식별 원본만 그대로 공개했습니다. 화면의 `100%`·응답 시간·도구 개수는 캡처 시점 표시이며 장기 가용성·성능·모든 도구 실행 검증 수치로 사용하지 않습니다.
